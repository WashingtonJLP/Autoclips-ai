# ADR 0001 — Monorepo e processamento econômico

Adotamos npm workspaces, NestJS para orquestração e FastAPI para mídia.
PostgreSQL mantém evidências de direitos; Redis mantém tarefas transitórias.
O servidor alvo possui i5-2310, 16 GB e nenhuma GPU. Whisper tiny em CPU/INT8,
duas threads e uma tarefa por vez são os padrões. Docker isola dependências.
URLs arbitrárias não serão baixadas automaticamente; a primeira versão aceita
apenas arquivos sob o diretório de mídia autorizado. Publicação é simulada.
